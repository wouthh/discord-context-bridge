# Third-party dependencies

Original project source is MIT licensed. No private project code is included.
Dependencies are referenced through package-lock.json, which pins versions and
registry integrity hashes; their own licenses continue to apply. The distributable
Vencord userplugin bundles Zod (MIT); its generated `core.js` retains upstream
license comments and is accompanied by Zod's MIT license in the generated output.
Vencord is GPL-3.0-or-later. A combined Vencord build must preserve its license,
notices and corresponding-source obligations; this repository does not distribute
Vencord itself. The MIT plugin is compatible with inclusion in that GPL build.
Vesktop has its own upstream license and notices. Do not strip dependency notices.
